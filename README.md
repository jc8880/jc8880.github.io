# Portfolio

A personal portfolio website built with plain HTML, CSS, and JavaScript — no frameworks, no build step. Deployed to GitHub Pages.

## Preview locally

Open `index.html` in a browser, or use the VS Code **Live Server** extension for auto-reload.

## Making Changes

Save files, then run these commands in the terminal:

1.  git add .
2.  git commit -m "Update portfolio"
3.  git push

## Other Notes

- Claude Bash does not work with rewind feature. Specify if experimenting
